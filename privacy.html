Privacy Policy

Last Updated: July 2026

This Privacy Policy explains how Text2Link ("the Add-on") handles information when you install and use it within Google Sheets. Your privacy is paramount, and this application is built to ensure complete data isolation.

Core Privacy Principle: Text2Link does not collect, store, track, share, or transmit any data from your spreadsheets or your Google Account. All data processing occurs entirely within your local active Google Spreadsheet session.

1. Data Collection and Transmission

The Add-on runs completely on Google Apps Script infrastructure. It does not utilize any external server, database, analytics tool, or third-party API. Because there is no backend server infrastructure, it is technically impossible for the developer or any outside entity to access your data.

2. Use of Google Workspace Scopes

Text2Link only requests the minimal permissions required to function. It adheres to the restricted execution model:

  • Spreadsheet Permissions (@OnlyCurrentDoc): The Add-on can only view and modify the specific Google Sheet that you actively have open when running the tool. It cannot access your broader Google Drive, other files, or unrelated spreadsheets.
  • User Interface (script.container.ui): This permission is used exclusively to build the custom menu buttons or sidebar panels inside your Google Sheet interface so you can click to run the tool.

3. Data Retention

No data is ever saved or cached by the Add-on. Any text manipulations occur instantaneously in-memory and are committed directly to your active spreadsheet file via secure Google APIs.

4. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted directly on this page. Your continued use of the Add-on following modifications constitutes acceptance of the updated terms.

5. Contact Information

If you have any questions regarding this Privacy Policy or the security of the Add-on, please open an issue on our GitHub project repository tracker.
